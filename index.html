Hospital ordering system

End-to-end ordering on behalf of hospital clients. A draft list, basket-building from a 3,475-product catalogue, line-level pricing with below-MSP warnings, manual picking, and SAP submission.

01

Interactive prototype

Click through orders, drafts, building a new order, editing line items, and submitting. Use the Tweaks toggle (top-right) to switch between split-view and stepped catalogue layouts, density, stock display, and the persistent client chip.

02

Canvas overview

All screens at once on a pan/zoom canvas. Click any artboard to focus full-screen. Includes layout variants side-by-side and design rationale notes.

Screens included

  1. Orders landing — list of submitted, on-hold and draft orders with KPIs, client filter, search, pagination
  2. New order modal — pick client account → pick order type (Hospital live; Bulk & NRT stubbed)
  3. Build order — catalogue search + filters + paginated list, basket panel with editable line items
  4. Line item edit — quantity, unit price (with below-MSP warning), line description
  5. Order metadata — order-wide description, shipping agent code, manual picking toggle with reason code
  6. Submission confirmation — SAP order ID returned
